## The line

A memory that never calls a model to work, and that learns from its own use which
memories are worth showing. Not allowed in any ADR: a second model to extract,
rerank or judge; idle rumination; vectors or scores handed to the model.

## Rules for every change

1. **Measure before installing.** A recall change runs on all three sets:
   `python neuron/bench/run.py --mode message --set neuron/bench/<set>.json` for
   `recall.json`, `recall_en_all.json`, `recall_en_text.json`. Accept only when,
   on every set: no expected fact lost, `full` not lower, `noise` and `off_topic`
   not higher. The English sets are the realistic case (Italian messages,
   English facts). The baseline is in the PLAN.
2. **Explore in a scratch script first.** Wrap `neuron.search._search_facts` from
   outside the repo, run `run_mode("message", data)` per variant, and only then
   edit the source. A stable choice sits on a plateau: its neighbours give the
   same result.
3. **The gate before a push:** `python tools/gate.py` (~10 min). A skipped step is
   a failed gate. The three suites never share a process.
4. **A real usage test before a commit.** Install, then use it:
   - install with `GM_HOME` set to the suite folder (the user's home,
     `GrayMatterEnvironment`), `GM_YES=1`, and
     `gray_matter/install.ps1 -Force -Client detected -EmbedModel sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`,
     output redirected to a log in the suite folder; the log must end with
     `INSTALL COMPLETE` and exit code 0. Without `GM_HOME` the installer falls
     back to a stale suite in `%LOCALAPPDATA%` and re-points every client at it.
     From inside Claude Desktop (an MSIX app, which redirects `%LOCALAPPDATA%`)
     launch it as a process outside the container:
     `Invoke-CimMethod -ClassName Win32_Process -MethodName Create`. This
     procedure is in `ENVIRONMENT.md`, section 4;
   - the install stops the clients' memory connection: they must be restarted;
   - anything that writes is tried on `python tools/isolated.py up` /
     `run -- <cmd>` / `down --purge`, never on the real memory;
   - never run tests with `GM_HOME`, `NS_GRAPHS_DIR` or `NEURAG_HOME` pointing at
     live data.
5. **English in the repo**: code, comments, output, changelog, docs, commits.
6. **Be gentle with the machine**: no full re-embedding runs without a GPU; long
   runs at below-normal priority. `NEURAG_EMBEDDER=null` gives lexical-only
   NeuRAG runs in seconds.

## Known traps

- **Backslashes in scripted edits.** A Python snippet passed through a Bash
  heredoc loses a level of backslash: `\b` became a backspace character inside a
  regex (2026-11-16). Edit regexes with an editor tool, or build the backslash
  with `chr(92)`; after a scripted edit, scan the file for control characters.
- **Every `#id` shown is "seen".** The hook and the gateway collect ids with
  `#([0-9a-f]{8})\b` and pass them back as `exclude`. Anything printed with a
  `#id` will not be recalled again in that session.
- **The hook file is deployed by copy.** `gray_matter/memhook.py` is copied to
  each client's hooks folder and runs with `python -I`; the smoke's cohesion
  check compares the copies with the repo. Do not edit it while a gate runs.
- **The bench set is frozen by rule.** `expect` is judged by reading the message,
  never widened after a miss: add a message and raise `version`.
- **`confirmed` counts use, not truth.** A disputed fact that is cited is "used".
- **Pin `PYTHONHASHSEED=0`** when calling `run_mode` from your own script:
  ranking ties follow set order.
